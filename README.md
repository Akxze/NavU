# NavU

Large File Size 246 MB
NavU is a navigation app designed for students who are struggling to find their way around the National University City campus. The app helps users locate rooms, buildings, and key destinations more easily.

## Overview

This project was created to make campus navigation simpler and more convenient for students. It aims to reduce confusion when trying to find classrooms, offices, and other important locations.

## Features

- Campus building and room navigation
- Easy-to-use interface
- Search for rooms or locations
- Helps students find their way around campus
- Built for student convenience

## Current Status

This app is still in development and has some limitations. Some features may not be fully functional yet, and some locations or routes may not be available.

Known issues:
- Some features are not yet optimized
- Some routes may not be available
- Some app functions may be limited
- Some data may not be fully complete

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/YourUsername/NavU.git
   ```

2. Open the project folder:
   ```bash
   cd NavU
   ```

3. Create a virtual environment:
   ```bash
   python -m venv venv
   ```

4. Activate the environment:
   - Windows:
     ```bash
     venv\Scripts\activate
     ```
   - Mac/Linux:
     ```bash
     source venv/bin/activate
     ```

5. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Running the App

Start the app with:

```bash
python main.py
```

If your project uses a different entry file, use that file instead.
